# m3u8 Downloader v4.2.3

本次补丁版本改善 Android B 站地址兼容性，并同步兼容模式开关的自动状态显示。

## 修复

- Android 播放和下载继续使用安全的网络连接。
- Android 流播页和下载页的“开启B站兼容模式”开关现在显示实际生效状态。
- 下载列表按每条地址分别判断兼容模式，混合下载普通地址和 B 站地址时不互相污染请求头。

## 发布资产

- Android：`m3u8-downloader-android-arm64-v8a-debug.apk`
- Linux：`m3u8-downloader_4.2.3_amd64.deb`
- Windows：`m3u8-downloader-4.2.3-windows-x64.exe`
- Windows：`m3u8-downloader-4.2.3-windows-x64.msi`
- 校验：`SHA256SUMS-linux-android.txt`、`SHA256SUMS-windows.txt`
