# m3u8 Downloader v4.2.3

本次补丁版本修复 Android B 站 CDN 地址被错误改写为明文 HTTP 的问题，并同步兼容模式开关的自动状态显示。

## 修复

- Android 保留 B 站 CDN 最终媒体地址的 HTTPS，避免触发 Android 网络安全策略的明文传输拦截。
- Android 流播页和下载页的“开启B站兼容模式”开关现在显示实际生效状态。
- 下载列表按每条地址分别判断兼容模式，混合下载普通地址和 B 站地址时不互相污染请求头。
