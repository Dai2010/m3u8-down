# m3u8 Downloader v4.1.0

本版本重点扩展多流媒体格式支持，并调整下载/流播链路：只有用户点击开始下载或开始流播后，才会识别目标媒体类型，减少输入阶段的额外请求，降低目标服务器封禁风险。

## 新增

- 媒体类型识别：支持按 URL、响应头和小范围内容探测 HLS/m3u8、DASH/mpd、Smooth Streaming、RTSP 与常见直链音视频。
- 桌面下载兜底：HLS 继续使用内部分片下载与广告过滤，DASH、Smooth Streaming、RTSP 和直链音视频改由 FFmpeg 下载保存。
- Android 格式支持：播放器切换到 Media3 通用媒体源，并加入 DASH、RTSP 和 Smooth Streaming 模块。
- Android 非 HLS 下载：通过内置 FFmpegKit 保存媒体 URL，保留 HLS 原有解析、过滤、下载和合并链路。

## 改进

- 桌面 CLI、GUI 和 TUI 的输入文案从 m3u8 URL 调整为媒体 URL。
- 流播开始后才识别类型；HLS 仍启动本地过滤代理，非 HLS 直接交给播放器打开原始地址。
- 默认输出文件名会根据输入 URL 推断扩展名，播放列表和清单类地址默认保存为 MP4。
- 新增媒体类型检测和 FFmpeg 下载路由测试，覆盖 CLI 非 HLS 分发路径。
