# m3u8 Downloader v4.2.4

本次版本根据 GitHub Issue #1 优化 Windows 桌面端的主题、复选框和流播探测交互。

## 改进

- 设置中的主题支持鼠标悬停即时预览，取消设置时自动恢复原主题。
- Windows 桌面端复选框使用明确的 `√` 勾选标记，替代整块填充效果。
- 流播地址旁新增“立即探测”按钮，输入框按回车也会立即触发探测，同时保留停止输入后的自动探测。
- Termux TUI 改为“下载 / 配置 / 日志”分栏，页面内容支持上下滑动，按钮在竖屏和小屏终端中按全宽排列。
- Termux TUI 的媒体探测等待时间缩短为 1 秒，并支持立即点击或按回车探测。
