# m3u8 Downloader v4.1.1

这是一个直链媒体下载修复版本，重点解决 `.m4a`、`.mp4`、`.mp3` 等普通音视频链接在 Android 和桌面端下载失败或保存扩展名不正确的问题。

## 修复

- 直链音视频下载不再交给 FFmpeg/FFmpegKit，而是使用 HTTP/OkHttp 直接保存，减少格式兼容问题。
- Android 下载请求默认携带移动浏览器 User-Agent，提升部分 CDN 音频直链的兼容性。
- Android 下载任务输出文件名默认留空，开始下载时按 URL 自动推断 `.m4a`、`.mp4`、`.mp3` 等扩展名。
- 桌面 GUI/TUI 在输出文件名留空时按 URL 自动推断扩展名。
- 直链下载使用 `.part` 临时文件，失败或取消时清理残留文件。

## 保持不变

- HLS/m3u8 仍使用原有分片下载、过滤和合并链路。
- DASH、Smooth Streaming、RTSP 等流媒体格式仍使用 FFmpeg/FFmpegKit 处理。
- 媒体类型检测仍只在点击下载或流播开始后触发，不在粘贴 URL 时提前请求。
