# m3u8 Downloader v5.0.2-pre-release3

Pre-release focused on Android Bilibili DASH M4S playback.

- Preserve Bilibili track URLs and query parameters during playback preparation.
- Select Bilibili tracks against Android decoder capabilities.
- Download and remux Bilibili M4S tracks with the existing FFmpeg path before handing a local MP4 to ExoPlayer.
- Keep ordinary media and m3u8 playback on the existing Media3 path.

This build still requires Android device playback verification before a stable release.
