# m3u8 Downloader v5.0.0

本版本更新桌面播放、B 站使用体验和跨平台发布产物。

## 播放与桌面端

- 桌面 GUI 继续使用内嵌 libVLC 播放直链和本地 HLS 代理流。
- Windows GUI 安装包内置 VLC 播放运行环境；Linux deb 使用系统 VLC，Android 使用 Media3。
- 播放失败或停止后会关闭相关后台任务。

## B 站 CLI

- CLI 支持普通视频页面、多 P、Cookie、画质、编码、音频语言和 HDR 选择。
- CLI 支持字幕、封面、弹幕、章节、信息 JSON 及临时文件保留选项。
- Linux deb 安装后可使用 `man m3u8-downloader` 查看完整参数。

## 构建与发布

- Build workflow 构建 Android、Linux、Termux 和 Windows 产物，并生成 SHA256 校验文件。
- Release workflow 汇总全部平台产物后统一创建 GitHub Release。
- Windows 发布包继续包含 GUI、CLI 和 TUI。

## 发布资产

- Android：`m3u8-downloader-android-arm64-v8a-debug.apk`
- Linux：`m3u8-downloader_5.0.0_amd64.deb`
- Termux arm64：`m3u8-downloader_5.0.0_termux_aarch64.deb`
- Windows：`m3u8-downloader-5.0.0-windows-x64.exe`
- Windows：`m3u8-downloader-5.0.0-windows-x64.msi`
- 校验：`SHA256SUMS-linux-android.txt`、`SHA256SUMS-windows.txt`
