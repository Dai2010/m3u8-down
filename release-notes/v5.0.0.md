# m3u8 Downloader v5.0.0

本版本聚焦跨平台播放、下载流程和日常使用体验优化。

## 使用体验

- 优化媒体地址识别和播放准备流程，减少重复探测与无效请求。
- 增强配置保存与恢复体验，桌面端、终端端和移动端保持一致的常用选项。
- 增加便捷的账号授权入口，完成授权后可自动保存并复用登录状态。
- 优化错误提示和失败恢复路径，减少需要手动重复填写的信息。

## 播放与下载

- 优化桌面端和移动端的播放体验与兼容性。
- 提升复杂媒体地址的播放稳定性，并改善中断后的继续处理体验。
- 优化多页面任务、附件保存和输出文件整理流程。

## 构建与发布

- 完善 Android、Linux、Termux 和 Windows 的构建流程。
- 发布包统一生成校验文件，便于下载后核对完整性。
- Windows 发布包继续提供 GUI、CLI 和 TUI 使用方式。

## 发布资产

- Android：`m3u8-downloader-android-arm64-v8a-debug.apk`
- Linux：`m3u8-downloader_5.0.0_amd64.deb`
- Termux arm64：`m3u8-downloader_5.0.0_termux_aarch64.deb`
- Windows：`m3u8-downloader-5.0.0-windows-x64.exe`
- Windows：`m3u8-downloader-5.0.0-windows-x64.msi`
- 校验：`SHA256SUMS-linux-android.txt`、`SHA256SUMS-windows.txt`
