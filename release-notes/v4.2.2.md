# m3u8 Downloader v4.2.2

本次版本统一了桌面端和 Android 端的媒体探测与操作入口，补充对无扩展名 MP4/fMP4、MPEG-TS 和常见音频直链的识别，并避免把直链误当成 m3u8 列表预览。

## 新增

- 输入链接停止 5 秒后自动探测媒体类型，并复用探测结果进行下载或流播。
- 通过响应头和少量媒体头识别无扩展名的 MP4/fMP4、MPEG-TS、Ogg、Matroska、MP3、AAC 等直链。
- 将 `.m4s` 纳入桌面端和 Android 直链下载路径；Android 导出时按 MP4 容器登记 MIME 类型。
- Android Media3 播放器对识别到的 `video/mp2t` 和 `video/mp4` 显式选择对应解析路径。
- 自动识别 B 站链接并补齐媒体请求头；兼容模式使用 B 站常见的 Referer、User-Agent，并对 B 站 CDN 采用 HTTP 兼容地址。

## 交互调整

- m3u8 全文预览只对探测结果为 HLS 的链接开放。
- MP4、M4S、MP3、M4A、TS 等直链不会触发 m3u8 预览请求。
- 无扩展名但响应为 HLS 的地址仍可预览，不再依赖 URL 后缀。
- 桌面 GUI 和 Android 的下载、流播页将 B 站兼容模式与去广告过滤收纳到“高级”区域，支持自动识别和手动开启。

## 发布注意

- Android APK 必须使用旧版升级私钥签名；Release workflow 会校验证书指纹，不匹配时停止发布。
