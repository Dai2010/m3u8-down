# m3u8 Downloader v5.0.3

## 重要变更

- 全平台正式下线 B 站兼容功能：CLI、GUI、TUI、Termux 和 Android 均不再提供 B 站专用解析、登录、Cookie、轨道选择、CDN 回退或播放兼容入口。
- 明确说明：此前版本中的 B 站兼容功能已确认不可用；该功能不再继续开发、修复、恢复或作为后续版本的支持范围。
- 其余通用媒体下载、HLS 分片、过滤、合并和代理功能保持可用。

## Android APK

- `arm64-v8a` APK 使用项目升级签名密钥签名。
- 发布流水线校验 APK 签名证书指纹后才上传 Release 资产。
