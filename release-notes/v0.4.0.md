# m3u8 Downloader v0.4.0

本版本重点补齐深色模式、配置文件管理和 Android 返回手势体验，同时继续通过 GitHub Actions 构建 Windows、Linux 和 Android 发布资产。

## 新增

- 深色模式：GUI、TUI 和 Android 均默认跟随系统主题，也支持手动切换浅色/深色。
- 配置文件管理：桌面 GUI、终端 TUI 和 Android 支持新建、修改、删除下载配置。
- 配置内容：配置文件可保存去广告开关、过滤关键词、线程数、保存目录、标签和备注。

## 改进

- Windows 主题适配：PyQt GUI 优先读取 Qt/Windows 系统配色，并补充 Windows 注册表检测。
- Linux 主题适配：支持 GNOME `gsettings`、KDE `kdeglobals`、`GTK_THEME` 和终端配色环境检测。
- Android 主题适配：Material3 浅色/深色配色同步系统状态栏和导航栏颜色。
- Android 返回手势：在流播、下载、配置、关于和播放器页面返回上一界面，不再直接退出或回到桌面。

## 发布资产

- Linux：`m3u8-downloader_0.4.0_amd64.deb`
- Windows：`m3u8-downloader-0.4.0-windows-x64.exe`
- Windows：`m3u8-downloader-0.4.0-windows-x64.msi`
