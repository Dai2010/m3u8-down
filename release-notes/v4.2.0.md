# m3u8 Downloader v4.2.0

本次版本增加 m3u8 原文预览与外观自定义，方便在开始播放/下载前按需查看列表内容，并让界面按钮颜色更贴近个人偏好。

## 新功能

- 桌面端与 Android 端新增“预览 m3u8 列表”，点击后才请求并展示 m3u8 完整全文。
- 预览阅读器采用更柔和的背景与等宽字体，减少长列表阅读时的刺眼感。
- 设置页将主题与按钮颜色压缩为“外观”设置项，减少设置入口层级。
- 支持通过预设调色板或 `#RRGGBB` 十六进制编码自定义主按钮颜色。

## 说明

- 预览不会在输入 URL 时自动探测或拉取列表，只有用户主动点击预览按钮才发起请求。
- 下载与流播的媒体类型识别仍保持在开始按钮点击之后执行，避免无意义请求。
- Android 端按钮颜色会持久化保存，并用于 Material 主题主色。
