# m3u8 Downloader v4.2.1

本次小版本修复自定义主题色只影响部分组件的问题，让外观设置中的颜色可以更完整地应用到 Android 与桌面端全局主题。

## 修复

- Android 端自定义颜色现在会派生完整 Material 3 色板，覆盖主色、容器色、辅助色、强调色、轮廓色和表面变体色。
- 桌面端自定义颜色现在会同步到 Qt 调色板高亮色、输入框焦点边框、选择色、进度条和次级按钮。
- 按钮、悬浮按钮、筛选标签、输入框、进度条、开关与单选按钮等默认组件会统一跟随自定义主题色。
- 保留浅色/深色模式下的背景和文字对比度，避免自定义颜色影响基础可读性。
